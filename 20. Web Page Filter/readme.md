# Web Page Filter

### Project Overview

A responsive web page filter application with search functionality and dynamic tag filtering. Users can search or filter items by tags, with a beautifully styled interface and an interactive design.

## Features 

- **Responsive Design**: Adapts seamlessly to different screen sizes.
- **Search Functionality**: Dynamically displays cards based on user input.
- **Tag Filtering**: Filters cards by categories such as `Books`, `Trees`, `Cats`, and more.
- **Interactive UI**: Hover effects, active tag indication, and smooth transitions.
- **Custom Background**: A fixed background image that spans the entire page.

## Tech Stack 

- **HTML**: Structuring the web page.
- **CSS3**: Styling, responsiveness, and hover effects.
- **JavaScript**: Dynamic filtering and event handling.

## Usage

### Search Bar

1.  Type a keyword (e.g., `books`, `trees`, etc.) into the search bar located at the top of the page.
2.  Press the search icon (magnifying glass) or hit Enter.
3.  The cards will dynamically display only those that match the search term.
4.  You can clear the search input to view all cards again.

### Tag Filtering

1.  Click on a tag button (e.g., `Books`, `Trees`, `Cats`, `Dogs`) to filter the cards according to the selected category.
2.  Clicking the `All` tag will display all cards.
3.  Cards that belong to the selected category will be shown, while the others will be hidden.
