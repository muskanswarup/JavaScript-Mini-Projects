# Tip Calculator 

A responsive Tip Calculator web application that allows users to calculate the tip amount and the per-person share based on the total bill, service quality, and the number of people sharing the bill.

## Features 

- **User-Friendly Interface**: A clean and intuitive design to input bill details, service quality, and number of people.
- **Real-Time Tip Calculation**: Automatically calculates the total tip and the tip per person.
- **Responsive Design**: Adapts seamlessly to different screen sizes, making it accessible on desktops, tablets, and mobile devices.
- **Error Handling**: Alerts users with appropriate messages when invalid inputs are provided (e.g., missing values, zero bill, etc.).

## Tech Stack 🛠

- **HTML**: Structuring the web page.
- **CSS**: Styling the application with responsive design principles.
- **JavaScript**: Handling user interactions and performing calculations dynamically.
