What is an algorithm?

An algorithm is a step-by-step procedure or formula for solving a problem or performing a task.

What is a data structure?

A data structure is a way of organizing and storing data in a computer so it can be accessed and modified efficiently.

What is the difference between a compiler and an interpreter

A compiler translates the entire program into machine code before execution, while an interpreter translates and executes code line-by-line.

What is the purpose of an operating system??

An operating system manages hardware and software resources and provides common services for computer programs.

What is recursion in programming?

Recursion is a programming technique where a function calls itself to solve smaller instances of a problem.

What is a database?

A database is an organized collection of data that can be easily accessed, managed, and updated.
