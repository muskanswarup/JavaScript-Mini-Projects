# Digital Clock

A simple, responsive digital clock built with **HTML**, **CSS**, and **JavaScript**. The clock displays the current date and time, updating in real-time with a sleek, modern design.

## Features

- **Real-Time Date and Time**: Displays current date and time that updates automatically.
- **Responsive Design**: Adapts to different screen sizes for desktop, tablet, and mobile devices.
- **Modern UI**: Clean, minimal, and modern user interface with a glowing effect for enhanced visual appeal.

## Demo

> **Live Preview:** [https://digitalclock-lemon.vercel.app/]

## Technologies Used

- **HTML5**: Structure of the web page.
- **CSS3**: Styling and responsiveness.
- **JavaScript**: Logic to display and update date and time in real-time.

## Project Structure

```
project-folder/
├── index.html        # HTML structure for the clock
├── style.css         # CSS styles for layout, responsiveness, and UI design
└── script.js         # JavaScript to display and update date & time in real-time
```

## Installation

1. **Clone the repository**:
    ```bash
    git clone [https://github.com/muskanswarup/JavaScript-Mini-Projects/tree/main/Digital%20Clock]
    ```

2. **Navigate into the project directory**:
    ```bash
    cd digital-clock
    ```

3. **Open `index.html` in your browser** to see the clock in action.

## Usage

1. Download or clone the project.
2. Open `index.html` in your web browser to view the live clock.

## Customization

- **Change Font**: Update the `font-family` in the `style.css` file to your preferred font.
- **Change Colors**: Modify color values in the `style.css` file to suit your design preferences.
- **Update Time Format**: You can adjust the date and time format in `script.js` to display in 12-hour or 24-hour format.

## Responsive Design

The clock is designed to be fully responsive and adapts to different screen sizes using CSS media queries. The layout adjusts for screens below **768px** and **480px**, ensuring a clean, user-friendly design on desktops, tablets, and smartphones.
