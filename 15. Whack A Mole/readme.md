# Whack a Mole

Whack a Mole is a fun and interactive browser-based game where players try to hit the moles while avoiding the potatoes to score as many points as possible within a limited time. The game features a sleek design and dynamic gameplay, making it a perfect choice for entertainment.

## Features

- Interactive game board with 9 tiles.
- Dynamic appearance of moles and potatoes.
- Timer-based gameplay (30 seconds).
- Scoring system for hitting moles.
- Game over modal with the final score display.
- Buttons to start, pause, and restart the game.
- User-friendly design with animations.

---

## Technologies Used

- **HTML** for the structure.
- **CSS** for styling and layout.
- **JavaScript** for game logic and interactivity.
- **Google Fonts** for custom typography.

## How to Play
 - Click the Start Game button to begin.
 - Whack the moles by clicking on them to earn points.
 - Avoid clicking on the potatoes, as it ends the game immediately.
 - Use the Pause Game button to pause and Restart Game to reset the game.
 - The game ends when the timer reaches zero or if you hit a potato.

## Game Logic

- **Timer** :  The game runs for 30 seconds. Each second is displayed on the timer.
- **Scoring**: Players gain 10 points for each mole clicked.
- **End Conditions**:
  - Timer reaches 0.
  - Player clicks on a potato.
- **Dynamic Elements**:
  - Moles appear every 2 seconds.
  - Potatoes appear every 3 seconds.
