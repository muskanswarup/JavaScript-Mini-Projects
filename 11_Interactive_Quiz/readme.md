# Quiz App

A modern, responsive quiz application designed to provide an engaging user experience. This app includes features such as light/dark mode, timer-based difficulty adjustments, score tracking, and a dynamic progress bar to enhance interactivity and challenge.

## Features

- **Light and Dark Mode Toggle**  
  - Users can switch between light and dark themes for better readability and personalization.

- **Timer-Based Difficulty**  
  - Each question comes with a countdown timer to increase challenge and engagement.

- **Score Functionality**  
  - Tracks user performance, displaying the final score at the end of the quiz.

- **Progress Bar**  
  - A visual indicator shows how far the user has progressed through the quiz.

- **Responsive Half-Screen Layout**  
  - **Desktop View**:  
    - Left side: Displays the question and timer.
    - Right side: Stylish answer buttons.  
  - **Mobile View**:  
    - Stacked layout for smooth interaction on smaller screens.

## Planned Enhancements

- **Hints System**: Optional hints to assist users with tricky questions.
- **Leaderboard**: Save and display high scores for competitive engagement.
- **Question Categories**: Allow users to select topics or difficulty levels.
- **Animations**: Smooth transitions between questions for a polished experience.

## Technologies Used

- **HTML5**: For semantic structure and layout.
- **CSS3**: For modern styling, responsive design, and animations.
- **JavaScript**: For interactivity, score tracking, and dynamic updates.
