# Memory Game with Anime

This project is a fun and interactive memory game featuring anime characters. It challenges players to match pairs of cards within the shortest time while keeping track of their score.

## Features

- **Dynamic Gameplay**: Flip cards to reveal anime characters and match pairs.
- **Score Tracking**: Earn points for correct matches and lose points for incorrect guesses.
- **Timer**: Track the time taken to complete the game.
- **Responsive Design**: The game is designed to work on various screen sizes.
- **Restart and Pause**: Restart the game at any time or pause/resume the timer.

## Technologies Used

- HTML
- CSS
- JavaScript
- Bootstrap

## How to Play

1. Flip two cards by clicking on them.
2. If the cards match, they remain flipped, and you earn points.
3. If they don't match, they will flip back after a short delay, and you lose points.
4. The game ends when all pairs are matched.
5. Check your final score and time upon completion.

## Game Controls

- **Restart Button**: Resets the game and shuffles the cards.
- **Pause/Resume Button**: Pauses or resumes the timer.

## How to Run

1. Clone this repository to your local machine.
2. Open the `index.html` file in your browser.
3. Start playing the game!
