# Meme Generator with Text Overlay
Create your own custom memes by adding text to uploaded images. This Meme Generator allows users to upload an image, input top and bottom text, and render the final meme on an HTML canvas.

## Features 

1. Upload any image for meme creation.
2. Input customizable top and bottom text.
3. Render the meme directly on the HTML canvas.
4. Responsive design to ensure usability on various screen sizes.

## Tech Stack 

- **HTML**: Structuring the web page.
- **CSS**: Styling the application with responsive design principles.
- **JavaScript**: Handling user interactions and performing calculations dynamically.
